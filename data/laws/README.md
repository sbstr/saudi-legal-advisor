# قاعدة بيانات الأنظمة (data/laws)

كل نظام يُخزَّن كملف JSON مستقل في هذا المجلد، بالصيغة التالية:

```json
{
  "id": "labor-law",
  "nameAr": "نظام العمل",
  "decree": "المرسوم الملكي رقم م/51 وتاريخ 23/8/1426هـ",
  "sourceUrl": "https://laws.boe.gov.sa/BoeLaws/Laws/LawDetails/08381293-6388-48e2-8ad2-a9a700f2aa94/1",
  "ingestedAt": "2026-09-09",
  "articles": [
    {
      "number": 1,
      "label": "المادة الأولى",
      "chapter": "الباب الأول: التعريفات وأحكام عامة",
      "text": "نص المادة كاملًا كما ورد في المصدر الرسمي..."
    }
  ]
}
```

## قواعد مهمة

- `id`: مُعرِّف قصير بالإنجليزية بدون مسافات (يُستخدم أيضًا كاسم الملف: `<id>.json`).
- `number`: ترقيم تسلسلي (1، 2، 3...) بحسب ترتيب ورود المواد في المصدر، بصرف النظر عن صيغة الترقيم الأصلية.
- `label`: نص رقم المادة كما ورد حرفيًا في المصدر (مثل "المادة الأولى" أو "المادة (39)") — هذا ما يُستخدم في الاستشهاد للمستخدم.
- `text`: النص الكامل للمادة بدون اختصار أو إعادة صياغة — الدقة هنا حرِجة لأن هذا محتوى قانوني.
- الملفات الأربعة المخطط لها في الدفعة الأولى: `labor-law.json`، `civil-procedure-law.json`، `enforcement-law.json`، `companies-law.json`.

## طريقة الإضافة

1. جهّز نص النظام الخام (نسخ من الموقع الرسمي أو استخراج من PDF) في ملف نصي.
2. شغّل `node scripts/ingest-law.js <ملف-النص> <law-id> "<اسم النظام بالعربي>"` لتوليد مسودة JSON تلقائيًا.
3. راجع المخرجات يدويًا (الأداة تقسّم على أساس كل سطر يبدأ بكلمة "المادة" فقط، فقد تحتاج تصحيحات يدوية بسيطة) قبل حفظها هنا نهائيًا.
